ПОИСК ПО ДАННЫМ ОБ УМЕРШИХ: ВЕРСИЯ ДЛЯ NETLIFY

В архиве:
public/index.html                 страница с SEO и счётчиком
netlify/functions/page-views.mjs   серверная функция
package.json                      зависимость функции
netlify.toml                      настройки публикации

1. Распакуйте архив на компьютере.
2. Откройте свой репозиторий на GitHub. В главной папке загрузите package.json и netlify.toml, а также папки public и netlify со всем содержимым. Пути должны совпадать с указанными выше. При необходимости загрузите файлы в папки по отдельности через Add file → Create new file, указывая путь в имени файла.
3. Если в корне репозитория уже есть старый index.html, оставьте его: новая версия берётся из public/index.html благодаря netlify.toml. Удалять старый файл не требуется.
4. Сделайте Commit changes. Netlify, подключённый к репозиторию, запустит новый deploy. Дождитесь Published и откройте сайт: счётчик находится внизу.
5. Если счётчик показывает «недоступно», проверьте статус deploy и Function logs в Netlify. Локальное открытие HTML или GitHub Pages не запускает функцию: там счётчик будет недоступен.

Считаются открытия и обновления страницы, не уникальные посетители. Счётчик начинает с нуля, считает ботов и может быть накручен: для точной аналитики нужен отдельный сервис. Значение хранится в Netlify Blobs и сохраняется при новых публикациях сайта. При высокой одновременной нагрузке часть запросов может завершиться ошибкой. Данные CSV и поисковые запросы на сервер счётчика не отправляются.

Публикация не гарантирует места в поисковой выдаче. Если сайт закрыт в Netlify, включите Project visibility → Public и затем запросите индексирование в Google Search Console.
